Medicine and Lab Ordering System
This is a full-stack application for medicine and lab ordering, designed for both consumers and operators. The application is built using Python with the Tkinter library for the graphical user interface and MySQL for the database.

Features
User Registration and Authentication: Allows users to register, log in, and manage their profiles.
Medicine Ordering: Consumers can search for and order medicines.
Lab Test Booking: Consumers can book lab tests.
Order Management: Operators can manage medicine orders and lab test bookings.
Database Management: All data is stored and managed using MySQL.
Technologies Used
Python: Core programming language used for application logic.
Tkinter: Python library used for creating the graphical user interface.
MySQL: Relational database management system used for storing user, order, and lab test data.
